### OpenAI发布MedChemBench基准测试 AI助力药物发现新里程碑

11月20日，OpenAI发布MedChemBench，这是一个评估AI模型在药物化学推理任务表现的基准测试：

**核心能力测试**：
- 分子结构重建：正确组装分子原子连接和立体化学
- 科学推理：基于实验证据解释结果
- 化合物排序与选择：满足研究需求的最优选择
- 性质预测：预测分子性质的数值和类别

**性能表现**：
- GPT-6.2 Astra在最高推理设置下获得84.5%的分数
- GPT-6 Astra获得83.3%，GPT-6.1 Sol获得82.0%
- GPT-5.6 Sol为58.2%
- 分子结构重建方面，Astra达到95.4%的准确率

**应用意义**：
- 帮助科学家识别有前景的候选药物
- 处理药物化学中的权衡问题（活性vs吸收率vs代谢稳定性）
- 为AI辅助药物发现提供标准化评估

### OpenAI公开Codex沙箱架构 终端安全新标杆

11月18日，OpenAI发布Codex沙箱技术详解：

**设计理念**：
- 深度防御（defense in depth）多层保护
- 用户可控的文件系统和网络限制
- 针对macOS、Linux、Windows的统一API

**默认权限策略**：
- 允许工作区写入，保持.git和.codex只读
- 允许广泛文件系统读取
- 默认禁用网络访问

**安全机制**：
- 子进程继承父进程沙箱约束
- 平台原生沙箱机制（非容器化）
- 控制室35秒内停止模型输出

### OpenAI前沿AI风险管理框架 从训练到部署的防御体系

11月18日，OpenAI发布前沿AI风险管理框架：

**四层防护体系**：
1. **安全与对齐**：模型内在的安全性
2. **安全控制**：沙箱和网络隔离
3. **系统级控制**：分类器和自动审查
4. **监控**：实时行为监测

**三阶段管理**：
- **研究阶段**：沙箱隔离，无互联网访问
- **内部部署**：测试对齐，密切监控
- **外部部署**：全面保护措施

**Control Room系统**：
- 35秒内停止模型输出
- 直接在推理基础设施中强制执行
- 前沿模型工作负载在控制室不可用时自动停止
