# AI日报 - 2026年9月30日

## 📰 今日头条

### OpenAI发布GPT-6.1 Sol：高性能低成本新模型

**核心亮点：**
- 性能接近GPT-6 Astra，成本仅为其五分之一
- 输入token定价：$2/百万（标准）、$0.10/百万（缓存）
- 输出token定价：$10/百万
- 在复杂编程、文档理解和多步骤商业工作流中表现优异
- 在DeepSWE v1.1测试中达到GPT-6 Astra水平，成本降低80%
- 自动化工作流测试（AutomationBench）得分提升4.8个百分点

**主要能力提升：**
1. **编程能力**：在DeepSWE 1.1复杂软件工程任务中与Astra持平
2. **专业工作**：PDF文档理解接近Astra水平，成本降低50%+
3. **计算机使用**：OSWorld 2.0测试中超越GPT-6 Sol 7个百分点
4. **科学研究**：Terminal-Bench Science测试得分翻倍，成本降低75%
5. **事实准确性**：事实错误率从11.4%降至7.7%

**定价策略：**
- 缓存输入token仅$0.10/百万，比标准输入便宜95%
- 面向Plus、Pro、Business、Enterprise和Edu用户开放
- 即将推出Ultrafast版本，生成速度提升8倍

### OpenAI推出革命性AI助手产品：Dots

**核心特性：**
- 基于GPT-6 Astra构建的智能代理系统
- 拥有独立的云端计算机和浏览器
- 可连接4000+应用，7×24小时持续工作
- 支持ChatGPT、Slack、Teams多平台交互
- 支持语音通话交互方式

**工作模式：**
- 自主处理任务，用户可随时查看进度
- 从用户反馈中持续学习和优化
- 可并行处理多个项目
- 团队协作版本即将推出

**实际应用案例：**
- 自动识别并修复代码bug
- 产品设计快速转化为可运行应用
- 自动生成发票和账单
- 研究数据分析与可视化

**适用范围：**
- Pro、Business Premium、Enterprise用户优先体验
- 支持文件管理、项目规划、客户支持等场景

### Claude科学突破：发现新型酶系统

**重大发现：**
- Claude自主发现具有CRISPR类特征的新型酶系统
- 系统基于逆转录酶（RT），具有DNA重复序列阵列
- 具有切割、复制、粘贴DNA的潜在能力
- 全程由AI主导，科学家仅提供初始提示

**研究过程：**
- 950个AI代理协作，耗时21小时
- 搜索分析了2.1亿个token的DNA序列数据
- 发现此前未知的DNA重复模式

**专家评价：**
MIT教授Feng Zhang表示："这是AI代理助力生物学发现的激动人心的例证。"
