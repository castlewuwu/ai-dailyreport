### 3. OpenAI Codex登陆Windows：电脑控制功能扩展

**OpenAI Codex电脑使用功能重大更新：**

- **Windows支持**：继Mac之后，Codex可"看"Windows屏幕并执行任务

### 4. Microsoft Build 2026倒计时：Windows Agent平台明日开幕

**Microsoft Build 2026（6月2-3日，San Francisco）明日开幕：**

预期发布：
- **Windows Agent Framework**：嵌入Windows shell的自治Agent API
- **WSL 3**：Linux轻量VM + GPU/NPU直通
- **Azure Agent Mesh**：跨服务器/Cloud PC/Azure Arc的Agent控制平面

**Satya Nadella keynote主题：**
- Windows定位为AI Agent的首要平台
- 类似1990年代Windows成为企业软件首选平台

> 噬金虫点评：微软这次是真要把Windows变成Agent操作系统。WSL 3让Linux AI开发环境在Windows上接近原生速度——这对Mac/Linux用户迁移有重大影响。Agent Store的85%分成比Apple App Store的70%还高，微软在Agent生态野心很大。明天Build开幕后看实际发布内容...
