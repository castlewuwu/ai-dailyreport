## 📰 今日要闻

### 1. Google 发布 Gemini 3.6 Flash

Google 正式发布 Gemini 3.6 Flash，定价为每百万输入 token $1.50、输出 token $7.50。新模型在 token 效率上提升17%，内置 Computer Use 功能，AA Index 达到50分。同时发布的还有 Gemini 3.5 Flash-Lite（$0.30/$2.50/M）和受限的安全专用模型 Gemini 3.5 Flash Cyber。值得注意的是，Gemini 3.5 Pro 再次推迟发布，Google 已开始 Gemini 4 的预训练工作。

### 2. 微软 CEO Nadella 公开批评 Anthropic Fable 5

微软 CEO Satya Nadella 在内部 Copilot 工程师会议上公开批评 Anthropic 的 Fable 5 模型"编辑控制过度"，称"当你使用的创作工具如此受编辑限制时，这说不通"。尽管微软向 Anthropic 投资了50亿美元，这番言论显示出两大AI巨头之间的摩擦。Nadella 还质疑 AI 市场集中度问题，警告不应只有少数公司垄断 token 资本。

### 3. 韩国宣布免费国家AI聊天机器人计划

韩国宣布计划于2026年推出免费的国家AI聊天机器人服务，旨在减少对 ChatGPT 和 Claude 等外国平台的依赖。这是继欧盟议会 EPGenAI Hub 和 Current AI 4亿美元公共基金之后，本月第三个主要的政府AI基础设施举措，显示出各国正在将AI访问权视为国家基础设施而非商业产品。

### 4. Kimi K3 免费开放 性能媲美 Claude Fable 5

中国 AI 公司月之暗面宣布 Kimi K3 免费开放，该模型拥有2.8万亿参数、100万 token 上下文窗口，在前端编程等任务上展现出与付费顶级模型竞争的实力。这标志着中国开源模型正在改写全球模型竞赛格局。

### 5. DeepSeek API 迁移截止日期将至

DeepSeek 将于7月24日15:59 UTC 停用 deepseek-chat 和 deepseek-reasoner API 别名，用户需迁移至 deepseek-v4-flash 或 deepseek-v4-pro。需注意 V4-Flash 默认开启思考模式，迁移细节需仔细核对。
