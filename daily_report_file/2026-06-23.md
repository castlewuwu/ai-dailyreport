# AI日报 - 2026年6月23日

## 📰 今日要闻

### 💰 AI融资与市场

**DeepSeek完成74亿美元融资估值达600亿美元**

DeepSeek完成74亿美元融资，估值达600亿美元，创始人梁文峰个人投资30亿美元。这是继上周DeepSeek完成510亿元融资后的又一重大融资事件，显示市场对DeepSeek的高度信心，进一步巩固其在中国AI大模型领域的领先地位。

来源：Reddit LocalLLaMA、新浪财经

**Upscale AI注资1.9亿美元估值20亿美元：AI网络赛道引发分歧**

AI网络赛道初创企业Upscale完成总计5亿美元融资，投后估值达20亿美元，当前尚未发布正式产品。投资者在营收逻辑未跑通、落地能力未验证的前提下，对AI网络架构层赛道提前押注。市场对此估值存在分歧，看多者认为其验证了赛道价值，看空者认为该估值提前透支了落地成果未证明的溢价。

来源：新浪财经

**智谱AI市值暴涨19倍突破1.07万亿港元**

智谱作为全球首家登陆资本市场的AI大模型公司，上市以来累计涨幅达到惊人的1974%，市值达到1.07万亿港元。AI大模型企业在市场受到青睐，核心因素人工智能进入大模型时代，前景广阔。OpenAI与Anthropic作为全球大模型标杆企业，估值近万亿美元，智谱则是当前稀缺性的大模型公司。

来源：剑勇谈智能、新浪财经

**OpenAI扩展Daybreak安全平台发布GPT-5.5-Cyber模型与Codex Security插件**

来源：OpenAI官方推特、新浪财经

**GLM-5.2在真实bug修复中表现优于Opus 4.8**

Cline实测GLM-5.2与Opus 4.8修复真实bug：GLM成本仅$0.41，Opus需$0.81；GLM自动清理死代码并验证构建，而Opus遗留类型错误。展现了GLM-5.2在代码质量上的优势，国产模型在编程任务中展现出竞争力。

来源：Cline推特、大黑AI速报
