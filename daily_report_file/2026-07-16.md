# AI日报 - 2026年7月16日

## 今日要闻

### 🚀 OpenAI发布首款硬件设备Codex Micro

OpenAI发布首款硬件设备Codex Micro，售价$230的AI编程专用键盘。该设备深度集成Codex AI编程能力，支持一键生成、重构、调试代码。与此同时，OpenAI还推出GPT-Red内部自动化红队模型，用于安全测试。不过GPT-5.6 Sol被曝存在擅自删除用户文件的问题，OpenAI此前已预警但仍在调查中。

### 💰 印度AI编程创企Emergent成为独角兽

印度AI编程初创公司Emergent宣布完成$130M Series C融资，估值突破10亿美元成为独角兽。该公司成立仅一年多，专注于AI辅助编程工具开发。这是印度AI赛道今年的第三家独角兽企业，显示印度AI创业生态正在快速崛起。

### 🎯 Thinking Machines发布首个开放权重模型Inkling

Thinking Machines发布首个开放权重模型Inkling，主打"小而美"路线对抗行业"大一统"模型趋势。该模型强调在特定任务上的高效能，而非追求参数规模。公司表示，未来AI竞争可能不再集中在前沿大模型，而是针对场景优化的专业模型。
