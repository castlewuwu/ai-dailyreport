#### 2. Embabel 智能体框架发布 1.0 正式版
Embabel 是一个用于在 Java 平台上构建 AI 智能体的框架，已发布 1.0 GA 版本。该框架由 Spring 框架创建者 Rod Johnson 联合创建，让 Java 与 Kotlin 开发者能够以类型化的领域对象（目标、动作及其连接条件）来声明智能体，而不是手工编码一系列的提示词与工具调用。

**核心特性**:
- 基于目标导向动作规划（GOAP）理念
- 构建在 Spring AI 之上
- 支持多模型混合环境运行
- 支持为单个动作指定特定模型
- 兼容 OpenAI、Anthropic、Gemini、DeepSeek 等主流模型

**来源**: [InfoQ](https://www.infoq.cn/article/5LJARsierf0NbH3Rc6wc)

### ☕ Java 生态

#### 4. Valhalla 项目首次预览：JEP 401 重新定义 Java 对象的 == 运算符
JEP 401（值对象预览版）已集成到 JDK 28 中。该提案引入了仅包含 final 字段、没有身份标识的类实例，并更改了这些对象中 == 运算符的行为。

**核心变化**:
- 新增 `value` 修饰符声明值类
- 值对象的 == 运算符基于字段值比较
- 为更扁平、无需内存分配的 JVM 表示形式铺平道路
- 性能优化：JVM 可将值对象标量化或扁平化为紧凑表示形式

**来源**: [InfoQ](https://www.infoq.cn/article/8grNo7eCm3Rly0NV8bcS)

### ☁️ 云服务与企业级 Agent 平台

#### 5. 阿里云发布 Agent Studio：All In One 企业级 Agent 全栈服务平台
阿里云将 Agent 相关服务能力升级为企业级 Agent 全栈服务平台——Agent Studio，正式上线阿里云百炼。

**核心能力**:
- **Managed Agent**: 托管式 Agent Runtime，支持长任务中断后继续执行
- **One Key Service**: 统一 API Key 接入多个 MCP 服务，首批接入 14 家云市场合作伙伴
- **Skill 体系**: 分为广场严选、服务商直供和用户自定义三层
- **Agentic Search**: 让 Agent 持续搜索、交叉验证信息，动态调整检索方向
- **Memory Studio**: 观察记忆、用户记忆和技能记忆三类记忆能力

**实际效果**: 保单条款审查从 3-4 小时缩短到约 15 分钟，效率提升十倍以上，单份保单成本仅 0.12 元。

**来源**: [InfoQ](https://www.infoq.cn/article/QekQuwv8UhxAcrOFgKM8)
