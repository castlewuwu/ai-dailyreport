### 💰 SuperGrok Heavy承诺变更:从"近乎无限"到"最高使用限制"

**核心变化:**
- SuperGrok Heavy上线时承诺"near-unlimited usage"(近乎无限使用)
- 该措辞已从定价页面消失,被替换为"highest usage limits"(最高使用限制)
- 价格维持在$300/月不变
- 社区报告显示日视频生成量从约100个降至约30个

**机制解析:**
付费Grok计划现在在Chat、Imagine、Voice和Build之间共享一个每周配额池。2026年6月已取消每两小时限制上限,因此图像和视频生成与日常对话共享同一预算。

**被忽视的中间层:**
Grok现在运行六个消费者层级:
- Free: 免费
- X Premium: $8
- SuperGrok Lite: $10
- SuperGrok: $30
- **SuperGrok Plus: $100**(最容易被忽视的层级)
- X Premium+: $40
- SuperGrok Heavy: $300

两个常见错误:
1. 为X Premium+支付$40却不需要社交功能(比SuperGrok贵$10且AI能力更弱)
2. 从$30直接跳到$300而不注意中间的$100层级

### 🏆 Pinecone Nexus检索层击败前沿模型

**重大突破:**
Pinecone Nexus达到正式可用(GA),在τ-Knowledge基准测试中取得最高分,击败使用OpenAI、Anthropic和Google前沿模型构建的智能体。

**关键洞察:**
- **相同模型,不同检索层,更好结果**
- 大多数团队两年都在优化模型,而将检索视为"管道工程"
- 这是测得的案例:管道决定了结果,而非模型

**模式匹配:**
本月多个案例显示约束不在模型能力:
- Linear遥测显示编码智能体将PR增加三倍,但未缩短周期时间(瓶颈在审查而非生成)
- Anthropic蛋白质结果来自指定目标而非选择目标
- Astra解决10个开放数学问题因为Lean可以即时检查答案

**教训:** 如果你想让智能体工作并试图获得更好的模型,请先检查检索——修复起来更便宜且更可能是问题所在。
