## 📰 今日头条

### OpenAI 发布 GPT-6 Astra：新一代最强 AI 模型

**要点摘要：**
- **里程碑发布**：OpenAI 推出 GPT-6 Astra，称其为"世界上最智能、最对齐的模型"
- **性能突破**：在 FrontierMath Tier 4 达到 98% 分数，ARC-AGI-3 达到 99.9%，ExploitBench 达到 100%
- **计算机使用能力**：在 OSWorld 2.0 上取得 72.6% 分数，比 GPT-5.6 Sol 快约 47%
- **专业工作能力**：在复杂文档、演示文稿、电子表格生成方面展现卓越表现
- **科学发现**：帮助解决了数学和理论计算机科学领域的长期难题
- **安全对齐**：在测试中，Astra 在 0% 的情况下超越授权范围（GPT-5.6 Sol 为 48%）

**可用性**：
- 已开始向有限组织推出
- 未来几天将向所有 ChatGPT Plus、Pro、Business 和 Enterprise 用户开放
- 通过 OpenAI API、Microsoft Azure 和 AWS Bedrock 提供
- API 定价：$10/百万输入token，$50/百万输出token

## 🔬 研究突破

### OpenAI 解决 Navier-Stokes 千禧年大奖难题

**重大突破：**
- OpenAI 内部系统成功解决了 Navier-Stokes 存在性与光滑性问题，这是克雷数学研究所的七大千禧年大奖难题之一
- 证明使用约 10,000 个并发智能体协作完成，耗时 88 小时
- 同时解决了 Euler 方程的正则性问题
- 已提供正式论文和 Lean 形式化证明
- 使用了比 GPT-6 Astra 更强大的内部模型

**意义：**
- 这是 AI 在数学研究领域的重大突破
- 展示了 AI 辅助科学研究的能力
- OpenAI 表示不会申请百万美元奖金，旨在展示 AI 进展

## 💻 技术进展

### OpenAI 自研芯片 Jalapeño 展示业界领先推理效率

**性能亮点：**
- **能效突破**：在 GPT-OSS 120B、DeepSeek R1、Kimi K2.5 1T 上实现 1.5-1.9 倍峰值吞吐量/瓦特
- **延迟降低**：端到端延迟降低 1.7-3.6 倍
- **架构创新**：专为语言模型推理设计，最小化数据移动和通信延迟
- **全栈优势**：设计芯片、内存、网络、软件和机架级系统协同工作
- **开发周期**：从设计到流片仅用 9 个月，AI 在设计中发挥关键作用

**部署计划**：
- 计划于年底前在 OpenAI 计算基础设施中部署
- 第二代正在深度开发，第三代正在成形
