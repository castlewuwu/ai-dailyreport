# AI日报 - 2026年6月28日

## 今日头条

### 🌏 亚洲AI公司抢占Mythos空白市场

**中国360公司推出Tulongfeng、日本Sakana AI发布Fugu模型**

随着Anthropic的Mythos和Fable 5模型出口禁令持续，亚洲AI公司迅速填补市场空白：

- **中国360公司**发布Tulongfeng AI工具，声称能与Anthropic的Mythos正面交锋。这款网络安全AI模型被美国政府禁止出口给非美国用户。

- **日本Sakana AI**推出Fugu模型（河豚命名），宣称"与Anthropic Fable 5和Mythos Preview肩并肩"。该模型专为Agent设计，可通过API编排其他模型。

Sakana AI联合创始人Ren Ito在G7峰会Evian会议上呼吁：美国应优先考虑"为最亲密盟友保留访问权"，而非将AI技术囤积。

**背景**：Anthropic的Mythos/Fable出口禁令发生在两周前，目前仍无解禁迹象。

### 🔒 Anthropic vs OpenAI竞争已成过去

**美国政府对两家公司采取相同限制措施**

TechCrunch评论文章指出，AI行业格局已发生根本变化：

- OpenAI的GPT-5.6发布同样遭遇政府审查，仅限预览版，需"逐客户批准"才能全面发布
- Mythos已处于预览状态数月，没有全面发布迹象
- 政府审查流程可能导致AI模型发布周期延长，影响数据中心建设投资

**核心观点**：OpenAI和Anthropic现在处于相同困境，面临相同灾难风险。对话中有人指责Anthropic搞监管捕获，有人指责OpenAI与特朗普合作打压对手——但实际上问题比这更大。

建立合理的模型发布流程需要行业共同努力：
- 信任独立团体引导过程
- 支持最不糟糕的监管选项，而非对抗每一项监管
- 为AI行业整体利益而战，而非将安全监管视为获取优势的机会

## 融资动态

### 💰 Patronus AI获5000万美元B轮融资

**构建"数字世界"测试AI Agent**

Patronus AI完成5000万美元B轮融资，由Greenfield Partners领投，Notable Capital、Lightspeed、Datadog、Samsung参投。总融资额达7000万美元。

**技术亮点**：
- 使用"数字世界模型"创建网站和内部系统副本
- 在这些环境中对Agent进行强化学习压力测试
- 类似Waymo训练自动驾驶汽车的方法：构建合成世界测试罕见危险场景

**市场需求**：几乎所有前沿AI实验室和许多初创公司都是客户。收入在过去一年增长15倍。

创始人Anand Kannappan表示：目前专注可验证问题（软件工程、金融），但还有大量难以验证的领域待开拓。

## 今日观点

### 政府审批流程的风险

如果预览仅持续"几周"，问题不大。但Mythos已预览数月。即使是几周的审查，也可能显著限制昂贵新系统的经济收益，恰逢AI实验室拼命改善收支平衡之时。

如果模型开发速度因此放缓，数据中心建设热潮也将降温。

**行业面临的整体风险**：整个行业可能面临危机，解决方案需要集体行动而非公司间竞争。
