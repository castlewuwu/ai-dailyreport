## 🤖 大模型

### 美团发布LongCat-2.0：国产算力训练万亿参数大模型

美团技术团队正式发布并开源万亿参数大模型**LongCat-2.0**，总参数达**1.6万亿**，平均激活约**48B**，动态范围33B-56B。该模型在**5万卡国产算力集群**上完成全流程训练与推理，采用LSA稀疏注意力、ScMoE及MOPD多专家融合架构，原生支持**1M超长上下文**，专为"Agentic Coding"任务设计。

SWE-bench Pro得分**59.5**，预览版已通过OpenRouter开放，月调用量跻身平台前列。这是行业首个万亿参数模型在国产算力上完成全流程训练。

**来源**: 美团官方技术博客

### OpenAI论文揭示GPT-5.6三个Pro变体

OpenAI论文首次披露**GPT-5.6的三个Pro变体**：Luna Pro、Terra Pro和Sol Pro，打破以往单一顶级Pro策略。在基因组学基准中，**Sol Pro通过率31.5%**居60个测试模型之首，领先标准Sol（28.7%）和Claude Opus 4.8（16.0%）。

Pro版本相比标准版提升逐级递减，Sol Pro仅提升2.8个百分点，暗示顶尖模型边际效益递减。

**来源**: OpenAI论文

### NVIDIA发布Nemotron-Labs-TwoTower扩散语言模型

NVIDIA发布基于冻结自回归骨干的扩散语言模型**Nemotron-Labs-TwoTower**，采用双塔架构。在2×H100上保留**98.7%的AR基线质量**，生成吞吐量提升**2.42倍**。模型总参数约**60B**，每token活跃参数约3B，降噪器在约2.1T token上训练，骨干使用25T token预训练。

**来源**: NVIDIA
