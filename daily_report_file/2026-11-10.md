### OpenAI 发布 Images 2.6 图像生成模型

**OpenAI 推出 Images 2.6，图像生成速度提升50%**
- OpenAI 于 11月4日正式发布 Images 2.6 图像生成模型
- 生成速度相比前代提升50%，低质量模式下最快6秒生成图像
- 提供两种模型变体：GPT-Image-2.6 Flare（速度优先）和 GPT-Image-2.6 Sunburst（质量优先）
- 全球每周生成图像数量达到40亿张，日均超过5亿张
- 支持 GIF 动画生成功能，可直接创建品牌吉祥物、表情包等动态内容
- API 新增图像标记功能、SVG导出和复杂度参数控制

**业界反响**
- OpenArt CEO Coco Mao 表示："GIFs是社交媒体的原生语言，GPT-Image-2.6让每位创作者都能从单个提示词流利地使用它"
- Figma Weave 创意总监 Itay Schiff："GPT-Image-2.6将速度和创意控制结合，帮助你在保留角色、产品或品牌细节的同时生成和编辑图像"

### OpenAI 发布 LifeVal 评估基准

**LifeVal：衡量AI在日常生活任务上的表现**
- OpenAI 于11月2日发布 LifeVal 评估基准
- 用于测量AI模型在日常生活重要任务上的进展
- 基于 American Time Use Survey 和 Multinational Time Use Study 数据集
- 覆盖照护、健康、教育、家庭管理、个人理财、购物、政府服务等领域
- 当前模型在多个任务上取得高分：
  - 寻找适合家庭的新居：100%完成率
  - 管理洪水准备志愿者：98%完成率
  - 远程陪伴祖母观看比赛：96.3%完成率
  - 幼儿园入学申请：93.1%完成率
  - 糖尿病饮食计划：90.4%完成率

**意义与价值**
- 标志AI从聊天工具向真正的代理式个人助手转变
- 超过10亿人每周使用ChatGPT，对实际生活帮助的需求日益增长
- 推动AGI更好地服务于全人类的日常生活
