## 🚀 OpenAI 重磅发布

### GPT-6.1 Terra：从视觉理解到行动

**发布时间：** 2026年10月26日

OpenAI 发布了 GPT-6.1 Terra，这是一款快速高效的模型，结合了详细的视觉推理和精确的计算机使用能力，以及更清晰、更自然的写作能力。

**核心亮点：**
- **性能提升：** 在 Agents' Last Exam 基准测试中，比 GPT-5.6 Terra 高出 15 个百分点，成本仅为其 1/3
- **成本优化：** API 价格比 GPT-5.6 Terra 和 GPT-6.1 Sol 低 50%
- **视觉推理：** 在 MMMU-Pro 基准测试中几乎匹配 GPT-6 Astra 和 GPT-6.1 Sol 的表现
- **计算机使用：** 在 OSWorld 2.1 测试中显著超越 GPT-5.6 Terra
- **编码能力：** 在 Terminal-Bench 4.0 上解决 50.3% 的任务，是 GPT-5.6 Terra 的两倍多
- **事实性改进：** 错误率从 53.6% 降至 16.7%（低推理设置）

**价格：** 
- 输入：$1/百万 tokens
- 缓存输入：$0.05/百万 tokens  
- 输出：$5/百万 tokens

**可用性：** 已向所有 Plus、Pro、Enterprise 和 Edu 用户开放

## 🤝 企业合作扩展

### OpenAI × ServiceNow：企业工作流全面集成

**发布时间：** 2026年10月28日

OpenAI 与 ServiceNow 扩大合作，将更多模型和代理带入 ServiceNow 产品，并连接 ServiceNow 工作流与 ChatGPT 和 Codex。

**合作内容：**
1. **ChatGPT 集成：** 将业务上下文和工作流操作直接带入 ChatGPT
   - IT 团队可以在 ChatGPT 中查找类似事件、评估变更风险、更新记录
   - 通过 ServiceNow 的 Action Fabric 应用现有业务规则和权限

2. **产品能力增强：**
   - **应用开发：** Codex 集成到 AI Workflow Factory，支持开发人员使用 ServiceNow 业务上下文
   - **网络安全：** 联合安全解决方案，结合 OpenAI 网络安全能力和 ServiceNow 资产管理
   - **语音功能：** 在 Super Intelligence Control Tower 中提供语音描述 AI 用例的体验

3. **内部部署：** ServiceNow 计划为所有员工提供 ChatGPT Work 和 Codex 访问权限

**时间表：**
- ServiceNow MCP 插件现已可用
- 增强功能预计 2026 年底推出
- 语音功能预计 2027 年第一季度推出

### OpenAI × Oracle：Oracle 应用全面接入 ChatGPT

**发布时间：** 2026年10月27日

OpenAI 与 Oracle 扩大合作，将 Oracle 应用和数据带入 ChatGPT，并使用 OpenAI 模型支持新的 Oracle 产品和服务。

**核心功能：**

1. **Oracle AI Workspace：** 在 ChatGPT 中集成 Oracle 应用和数据
   - 财务团队可以调查成本、理解采购决策、识别月末结账前剩余工作
   - 跨财务、采购和规划应用整合信息

2. **新产品推出：**
   - **Oracle AI Security Mesh：** 使用 OpenAI 网络模型帮助客户发现和修复应用程序及基础设施漏洞
   - **Oracle AI SMB Bundle：** 结合 ChatGPT Business 和 Codex，面向中小企业
   - **Oracle App Composer：** 使用 Codex 和其他 AI 工具构建应用，连接 Oracle 数据和工作流

3. **使用规模：** Oracle 报告 13 万活跃 ChatGPT 用户，9.5 万活跃 Codex 用户

**可用性：** 美国客户可通过 Oracle Marketplace 购买 OpenAI API、Codex 和 ChatGPT Work

## 💡 Google AI 更新

### Gemini 4 Argon 正式上线

**发布时间：** 2026年10月13日

Gemini 4 Argon 现已在 Gemini 应用中可用，提供前沿推理和改进的复杂任务性能。

**核心特性：**
- **更直接的回答：** 减少不必要的谨慎，避免过度重复，跳过陈词滥调
- **更好的进度反馈：** 在处理长任务时更频繁、更有效地分享进度
- **编程改进：** 重大编码能力提升
- **任务模式：** 在主聊天窗口中轻松切换聊天和任务模式，Gemini 可以在您不在电脑前时继续工作

**应用集成：** 现已连接 40 多个应用，包括：
- Instacart（杂货配送）
- OpenTable（餐厅预订）
- Adobe（设计和创意）
- Shopify（电商）

**可用性：** Google AI Pro 和 Ultra 订阅用户可立即访问
