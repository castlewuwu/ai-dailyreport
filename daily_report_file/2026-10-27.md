## 🤖 产品与发布

### GitHub 前 CEO 推出 Entire 平台，专为 AI Agent 设计
GitHub 前 CEO Thomas Dohmke 正式推出 Entire 平台，这是一个专为 AI agent 与人类协作设计的分布式代码平台。平台采用"Trails"功能替代传统的 pull request，提供可定制的评估机制，让 AI agent 在每次代码推送时都能获得评分。这代表了软件开发工作流程的重大变革。

**来源**: The Verge

### Grok 发布 AI 生成电影《奥德赛》片段
Grok 发布了 AI 生成的电影《奥德赛》前七分钟片段，这是首部 AI 生成的史诗级电影作品。尽管 Elon Musk 曾承诺这是一部"全长电影"，但目前只发布了片段。视频存在角色面部不一致、盔甲不符合历史等问题，但仍然展示了 AI 在视频生成领域的突破性进展。

**来源**: TechCrunch, The Verge

### Block 发布 Dessa 超拟人语音模型
Jack Dorsey 的 Block 公司发布了名为 Dessa 的新一代语音模型，该模型完全通过语音训练，听起来"超拟人化"，被形容为"像一个尴尬的新朋友"。模型的独特之处在于无需文本转语音，直接从语音数据学习，展现了 AI 语音技术的最新进展。

**来源**: TechCrunch, The Verge

### Marissa Mayer 推出 Dazzle AI 助手

**来源**: The Verge
