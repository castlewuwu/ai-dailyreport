# AI日报 - 2026年6月19日

## 📊 行业动态

### 中国服务外包产业20年增长超200倍，AI重塑行业价值逻辑

**核心要点**：
- 第十五届中国国际服务外包交易博览会在武汉开幕
- 中国服务外包合同执行金额从13.8亿美元增至3032.4亿美元，增长220倍
- 企业数量从500家增至9万家，增长180倍
- 从业人员从6万人增至1765.5万人，增长294倍
- AI技术推动产业从低端执行转向高端研发，生成式AI可自动完成41%的基础编码客服类工作

**影响分析**：AI正在彻底重塑服务外包产业的价值创造逻辑，传统人力成本优势正被高效算法替代，产业正向高附加值领域转型升级。

### 福建深入实施"人工智能+"行动，构建特色现代化产业体系

**核心举措**：
- 设立省级大模型专项攻关基金，聚焦海洋经济、闽台融合等特色优势领域
- 组建"福建省人工智能自主创新联合体2.0"
- 推动福州、厦门、泉州智算中心集群建设
- 推广"算力券"模式降低用算成本
- 建设全省一体化数据要素市场

**产业布局**：重点发展工业软件、智能制造外包赛道，输出AI+政务+农业+智能港口等特色解决方案。

### 科创板第五套标准扩围至大模型企业，智谱、MiniMax"回A"提速

**政策背景**：上交所发布《人工智能大模型企业适用科创板第五套上市标准》指引

**影响**：
- 智谱、MiniMax等头部大模型企业"回A"有望提速
- 境内投资者将获得直接定价大模型核心资产的入口
- 产业资源加速向头部玩家集中
- 国产大模型的本土资本链与供应链有望形成共振
